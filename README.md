# nacer-apesta

Canal "Nacer como un [animal] apesta": videos animados de 8 minutos.

- `motor/`: motor de dibujo, voz (Piper), render y mezcla de audio.
- `ejemplo_pulpo/`: guion, personajes, tomas y efectos del episodio del pulpo (referencia para nuevos animales).
- Rama `media`: el video y la miniatura del día (se sobrescribe cada día; Metricool copia el archivo al programar).
