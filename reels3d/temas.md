# Temas (un video por día, sin repetir)
Todos con Santi (programador) y Claude (robot IA). Humor ligero, sarcasmo tierno del robot.
1. Claude se queda sin uso y Santi hace la web solo (HECHO)
2. Santi le pide a Claude "un cambio chiquitico" que reescribe todo el proyecto
3. Bug a las 3 a. m.: Santi culpa al robot, el error era un punto y coma
4. Santi le pregunta a Claude si su código está bien; Claude, educado, enumera 47 problemas
5. "Funciona en mi computador" — el cliente abre la web y todo explota
6. Santi pide a Claude que haga la app "como Instagram pero mejor", en 5 minutos
7. Claude propone un plan de 12 pasos; Santi dice "hazlo todo de una"
8. Santi copia código de internet sin leerlo; el robot lee el comentario "NO USAR EN PRODUCCIÓN"
9. Santi olvida guardar el archivo y pierde 4 horas de trabajo
10. Claude revisa el código de Santi y encuentra una variable llamada "cosa2_final_AHORA"
11. Santi quiere que la web "se sienta cálida" y Claude pregunta cuántos grados
12. El cliente pide "un botón más grande" 17 veces
13. Santi le dice "gracias" a Claude y el robot se emociona demasiado
14. Reunión con el cliente: Santi promete cosas imposibles, Claude lo mira en silencio
15. Santi intenta arreglar un bug con "apagar y prender", y funciona; nadie entiende por qué
16. Claude dice "no puedo hacer eso" y Santi intenta convencerlo con chantaje emocional
17. Contraseña olvidada: Santi tiene "Contraseña1234" y Claude se estremece
18. Santi pide un logo: Claude propone un cuadrado; Santi aprueba "minimalista"
19. Mudanza al servidor nuevo: lo que podía salir mal salió mal
20. Santi descubre que llevaba 2 horas editando el archivo equivocado
